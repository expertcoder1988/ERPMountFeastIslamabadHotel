# Mount Feast Islamabad - Hotel ERP

Enterprise desktop **Hotel ERP** built for Mount Feast Hotel (Islamabad). Covers day-to-day hotel operations in a modular Windows application.

## Overview
Full hotel management ERP focused on property operations: front-office workflows, back-office accounts, inventory, and supporting modules used by hotel staff.

## Key Features
- Hotel operations and property management workflows
- Accounts / financial records support
- Inventory and resource tracking
- Modular desktop ERP architecture for hotel departments
- SQL Server-backed enterprise data model

## Tech Stack
- **Language:** Visual Basic .NET (VB.NET)
- **UI:** Windows Forms / desktop ERP modules
- **Database:** Microsoft SQL Server
- **IDE:** Visual Studio

## Project Structure
- `Hotel ERP System v6.0/` - main ERP application modules and resources
- `Resources/` - icons and supporting assets

## Getting Started
1. Open the solution in **Visual Studio**
2. Restore any required NuGet / project references
3. Configure SQL Server connection settings for your environment
4. Build and run the desktop application
